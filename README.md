# 🎮 بازی Hangman (مرحله‌ای)

بازی حدس کلمه‌ی انگلیسی. سیستم یک کلمه را از یک دسته‌بندی انتخاب می‌کند و بازیکن باید با حدس زدن حرف‌ها، کلمه را پیدا کند. با هر حدس اشتباه، شخصیت به اعدام نزدیک‌تر می‌شود.

## منطق اصلی بازی

1. بازیکن یک **دسته‌بندی** انتخاب می‌کند.
2. سیستم از بین کلمات انگلیسیِ آن دسته، یک کلمه را به‌صورت تصادفی انتخاب می‌کند.
3. کلمه به‌صورت پنهان نمایش داده می‌شود؛ هر حرفِ ناشناخته با `-` نشان داده می‌شود.
4. بازیکن در هر نوبت **فقط یک حرف** وارد می‌کند.
   - اگر حرف در کلمه باشد، در تمام جاهایی که آمده آشکار می‌شود.
   - اگر نباشد، یک فرصت از دست می‌رود و تصویر hangman یک مرحله جلو می‌رود.

### مثال

کلمه‌ی انتخاب‌شده: `dentist` (۷ کاراکتر)

```
d e n t i s t
0 1 2 3 4 5 6
```

| ورودی | نتیجه |
|-------|-------|
| شروع بازی | `-------` |
| `d`   | `d------` |
| `t`   | `d--t--t` |

## قوانین حروف و فرصت‌ها

- الفبای انگلیسی ۲۶ حرف دارد.
- **۵ مصوت** (`a e i o u`) حروف «بدون مجازات» هستند.
- **۲۱ حرف باقی‌مانده** (همخوان‌ها) حروفی هستند که حدس اشتباهشان شمرده می‌شود.
- **حداکثر ۱۰ حدس اشتباه** مجاز است. با اشتباه دهم، بازی تمام می‌شود.
- تعداد فرصت‌ها **ثابت (۱۰)** است و به طول کلمه بستگی ندارد.

### ⚠️ رفتار مصوت‌ها

سه حالت ممکن است؛ پیش‌فرض پیشنهادی حالت **الف** است:

| حالت | توضیح |
|------|-------|
| **الف (پیشنهادی)** | مصوت‌ها از ابتدای بازی در کلمه آشکار هستند. |
| ب | مصوت‌ها خودکار پر می‌شوند و بازیکن نمی‌تواند انتخابشان کند. |
| ج | بازیکن می‌تواند هر ۵ مصوت را بدون جریمه امتحان کند؛ بعد از آن جریمه اعمال می‌شود. |

### ⚠️ حرف `y`

حرف `y` گاهی نقش مصوت دارد (مثل `gym`). پیش‌فرض: **`y` همخوان حساب می‌شود**. کلماتی که هیچ مصوتی ندارند (مثل `gym`) یا باید از لیست حذف شوند یا `y` برای آن‌ها مصوت در نظر گرفته شود.

## جریان بازی

```
انتخاب دسته‌بندی
      │
      ▼
انتخاب کلمه توسط سیستم
      │
      ▼
 ┌─► دریافت یک حرف ──► حرف در کلمه هست؟
 │                        │ بله: آشکار شدن حرف
 │                        │ خیر: کم شدن یک فرصت
 │                        ▼
 │               کلمه کامل شد؟ ──بله──► برنده‌ی مرحله ──► مرحله‌ی بعد (کلمه‌ی جدید)
 │                        │ خیر
 │               فرصت‌ها تمام شد؟ ──بله──► Game Over + نمایش امتیاز نهایی
 └────────────────────────┘ خیر
```

- با **برنده شدن** در یک مرحله، کلمه‌ی بعدی انتخاب می‌شود و امتیاز جمع می‌شود.
- با **باخت** (اتمام ۱۰ فرصت)، بازی تمام می‌شود و **امتیاز کل همه‌ی مراحل** نمایش داده می‌شود.
- دکمه‌ی **«جدید»** بازیکن را به صفحه‌ی انتخاب دسته‌بندی برمی‌گرداند.
  - ⚠️ پیشنهاد: اگر وسط بازی زده شد، قبلش پیام تأیید نشان داده شود چون امتیاز جمع‌شده از دست می‌رود.

### ⚠️ حدس کل کلمه

در منطق اولیه آمده بود «اگر کلمه اشتباه حدس زده شود بازی تمام می‌شود». این با سیستم ۱۰ فرصت هم‌خوانی ندارد. دو گزینه:

- **پیشنهادی:** فقط حدس حرف وجود دارد و بازی با اتمام ۱۰ فرصت تمام می‌شود.
- جایگزین: یک مکانیزم جداگانه‌ی «حدس کل کلمه» که حدس غلطش فوراً باخت است.

## وضعیت‌های بازی (States)

| وضعیت | توضیح |
|-------|-------|
| `CATEGORY_SELECT` | صفحه‌ی انتخاب دسته‌بندی |
| `PLAYING` | بازیکن در حال حدس زدن است |
| `STAGE_WON` | کلمه‌ی مرحله درست حدس زده شد |
| `GAME_OVER` | فرصت‌ها تمام شد؛ نمایش امتیاز نهایی |

انتقال‌ها:

- `CATEGORY_SELECT` → `PLAYING` (انتخاب دسته)
- `PLAYING` → `STAGE_WON` (کلمه کامل شد)
- `PLAYING` → `GAME_OVER` (۱۰ اشتباه)
- `STAGE_WON` → `PLAYING` (مرحله‌ی بعد)
- هر وضعیت → `CATEGORY_SELECT` (دکمه‌ی «جدید»)

## اعتبارسنجی ورودی

| ورودی | رفتار |
|-------|-------|
| خالی | نادیده گرفته می‌شود، پیام راهنما |
| بیش از یک کاراکتر | رد می‌شود، پیام خطا |
| عدد، فاصله، نماد | رد می‌شود، پیام خطا |
| حرف بزرگ یا کوچک | یکسان حساب می‌شود (تبدیل به lowercase) |
| حرفی که قبلاً حدس زده شده | **جریمه نمی‌شود**؛ فقط پیام «قبلاً این حرف را زدی» |
| حرف غیرانگلیسی | رد می‌شود |

همچنین لیست **حروف اشتباه حدس‌زده‌شده** به بازیکن نمایش داده شود.

## امتیازدهی

> ⚠️ فرمول امتیاز هنوز نهایی نشده است. پیشنهاد اولیه:

- هر مرحله‌ی موفق: **امتیاز پایه** (مثلاً ۱۰۰)
- **پاداش فرصت باقی‌مانده:** به ازای هر فرصت استفاده‌نشده (مثلاً ۱۰ امتیاز)
- ⚠️ اختیاری: ضریب طول کلمه، ضریب سختی دسته، یا ضریب پشت‌سرهم‌بودن (streak)

```
امتیاز مرحله = امتیاز پایه + (فرصت‌های باقی‌مانده × پاداش هر فرصت)
امتیاز نهایی = مجموع امتیاز مراحل برنده‌شده
```

امتیاز نهایی هنگام `GAME_OVER` نمایش داده می‌شود.

## ذخیره‌ی مراحل نزدیک به باخت

اگر بازیکن مرحله‌ای را ببرد ولی **۹ حدس از ۱۰ حدس اشتباه** را استفاده کرده باشد، اطلاعات زیر ذخیره می‌شود:

- نام مرحله
- تعداد حروف اشتباه

### ⚠️ موارد نیازمند تصمیم

- **آستانه:** فقط دقیقاً ۹ یا «۸ و بیشتر»؟ (پیشنهاد: `>= 8` و قابل‌تنظیم)
- **محل ذخیره:** حافظه‌ی موقت، فایل (مثل JSON)، یا دیتابیس؟
- **هدف:** نمایش به‌عنوان «دستاورد»، یا یک لیست «نزدیک بود ببازی»؟

## انتخاب کلمه و دسته‌بندی

- کلمات در **دسته‌بندی‌های** جدا نگهداری می‌شوند (مثلاً: حیوانات، شغل‌ها، غذاها).
- ⚠️ منبع لیست کلمات: فایل JSON/متنی، دیتابیس، یا API (پیشنهاد برای شروع: فایل JSON).
- **جلوگیری از تکرار:** کلمه‌ای که در همین جلسه آمده دوباره انتخاب نشود.
- ⚠️ **سطح سختی:** مراحل بالاتر می‌توانند کلمات طولانی‌تر یا کمیاب‌تر بیاورند تا «مرحله‌ی بعد» فقط یک کلمه‌ی جدید نباشد.

### نمونه‌ی ساختار داده

```json
{
  "animals": ["elephant", "giraffe", "penguin"],
  "jobs": ["dentist", "teacher", "engineer"]
}
```

## حالت‌های لبه برای تست

- کلمه‌ای با حرف تکراری زیاد (مثل `letter`، `banana`)
- کلمه‌ای با مصوت‌های بسیار کم (مثل `rhythm`، `gym`)
- کلمه‌ی خیلی کوتاه
- حدس تکراری یک حرف
- ورودی نامعتبر (عدد، نماد، چند حرفی، خالی)
- حدس حرف بزرگ و کوچک (`A` و `a`)
- برنده شدن با دقیقاً ۹ یا ۱۰ اشتباه
- زدن دکمه‌ی «جدید» وسط بازی

## ایده‌های اختیاری

- 💡 **راهنما (Hint):** با از دست دادن یک فرصت، یک حرف آشکار شود.
- ⏱️ **تایمر** برای هر مرحله
- 🖼️ **تصویر hangman** در ۱۰ مرحله، هماهنگ با ۱۰ فرصت
- ❌ نمایش جداگانه‌ی حروف اشتباه حدس‌زده‌شده
- 🏆 جدول رکوردها (ثبت نام و امتیاز)
